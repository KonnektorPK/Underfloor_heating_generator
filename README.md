# Генератор тёплого пола для Revit

Надстройка извлекает сплайны из импортированного DWG и создаёт по ним трубы тёплого пола. Интерфейс WPF открывается как одно модальное окно с вкладками.

## Структура проекта

```text
Application/
  Contracts/       интерфейсы сценария и Revit-операций
  Models/          параметры запроса, варианты выбора, результат
  Services/        сценарий генерации тёплого пола
Infrastructure/
  Revit/           чтение документа, DWG и построение труб через Revit API
Revit/
  App.cs           регистрация кнопки на ленте
  Commands/        точка входа команды Revit и сборка зависимостей
Resources/Icons/   PNG для ленты Revit, ICO для окна WPF
UI/Views/          XAML-окно, вкладки и обработчики взаимодействия
Build/             результат сборки, addin-файл и иконки
```

## Архитектурные правила

- `GenerateWarmFloorCommand` — точка входа и composition root: создаёт реализации и передаёт их через конструкторы.
- `MainWindow` отвечает за отображение, ввод и проверку пользовательских значений. Построение делегируется интерфейсу `IWarmFloorGenerator`.
- `WarmFloorGenerationService` координирует сценарий через контракты; инфраструктура Revit отвечает за получение элементов, геометрию DWG и транзакции.
- Контракты разделяют чтение параметров и построение, чтобы заменять реализации и добавлять сценарии без изменения окна.
- Модели `WarmFloorRequest`, `ElementOption` и `WorkflowResult` передают данные между слоями.

Это разделяет обязанности (SRP), позволяет расширять реализацию без переписывания UI (OCP), передаёт сервисам контракты (DIP), а небольшие интерфейсы соответствуют ISP. Наследование между несвязанными слоями не используется; реализации взаимозаменяемы через интерфейсы (LSP).

## Сборка

Проект нацелен на Revit 2026 и .NET 8 (`net8.0-windows`). При другом расположении Revit переопределите `RevitInstallDir` в параметрах MSBuild.

```powershell
dotnet build Underfloor_heating_generator.csproj -c Debug
```

Сборка помещает DLL, `.addin`, PNG и ICO в `Build`. Путь к DLL записывается в копию `.addin`. ICO также включён в WPF-ресурсы и задаёт `Window.Icon`.

## Добавление новой вкладки

Добавьте вкладку в `UI/Views/MainWindow.xaml`. Отделяйте её пользовательский сценарий в отдельный сервис в `Application/Services`, объявляйте нужный контракт в `Application/Contracts`, а доступ к Revit API размещайте в `Infrastructure/Revit`. Команду и сборку зависимостей оставляйте в `Revit/Commands`.
