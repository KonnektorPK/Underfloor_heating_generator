# Плагин автоматического проектирования тёплого пола по сплайнам DWG

## 📌 Описание работы плагина Revit

Данный плагин предназначен для автоматического создания контуров **тёплого пола** в Autodesk Revit 2024 и далее на основе **сплайнов из DWG-чертежа**.

Плагин анализирует импортированный или связанный DWG-файл, извлекает сплайны и по ним строит трассировку труб тёплого пола непосредственно в модели Revit.  
Все основные параметры настраиваются через удобную **UserForm**.

Плагин разработан с использованием **Revit API** на языке **C#**.

---

## 🚀 Основные возможности

- 📐 Чтение сплайнов из DWG-чертежей
- 🔁 Автоматическое построение контуров тёплого пола по сплайнам
- 🧮 Гибкая настройка параметров через пользовательскую форму:
  - диаметр трубы
  - высотная отметка
  - тип системы / семейства
- 🧩 Интеграция напрямую в среду Autodesk Revit
- ⚡ Существенное ускорение процесса проектирования

---

## 🖼 Принцип работы

1. В проект Revit подгружается или связывается DWG-чертёж  
2. Пользователь запускает плагин
3. В UserForm задаются параметры тёплого пола
4. Плагин:
   - находит сплайны в DWG
   - преобразует их в кривые Revit
   - строит по ним контуры труб тёплого пола

---

## 🛠 Используемые технологии

- **Язык программирования:** C#
- **API:** Autodesk Revit API
- **UI:** Windows Forms (UserForm)
- **Формат входных данных:** DWG
