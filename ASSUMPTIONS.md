# Допущения

- Название окна — «Генератор тёплого пола». Пользователи — проектировщики ОВиК, работающие в Revit 2026.
- В проекте два сценария. Первый переводит DWG в трубы, второй строит контуры по выбранной области. Текущий стек WPF и команды Revit задают границы редизайна.
- Язык интерфейса — русский. В настройках указан текущий язык. Выбор других языков потребует перевода сообщений, включая сообщения сервисов и подсказки Revit.
- Автоматическая тема следует настройкам Windows. Контрастная тема Windows имеет приоритет над выбором пользователя. Масштаб интерфейса применяется поверх системного DPI.
- В проекте не было дизайн-системы и каталога `design-refs`. Инструменты поиска референсов из ТЗ не подключены. Использованы рекомендации Microsoft и текущие рабочие сценарии плагина.
