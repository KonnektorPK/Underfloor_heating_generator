# Интерфейс генератора тёплого пола

## Аудит

Окно уже разделяет два сценария, запоминает параметры и возвращает пользователя на план для выбора области. Сейчас действия скрываются при вертикальной прокрутке, выбранные элементы теряются среди полей, а ошибки объясняются одной строкой внизу. У вкладки помещения нет отдельной индикации ожидания.

Две верхние вкладки сохраняют переход между сценариями за одно действие. Вкладки используют привычную навигацию WPF. Заголовок и команда построения остаются на месте, параметры прокручиваются между ними. Настройки открываются из заголовка. Системная рамка даёт привычные команды окна и изменение размера.

Размеры заданы в DIP. Шрифт — Segoe UI Variable Text с запасным Segoe UI. Шкала текста — 12, 14, 16 и 24. Шаг отступов — 4, 8, 12, 16, 24, 32. Радиусы — 6 для контролов, 12 для секций. Глубину передают поверхности и тонкие границы. Переходы мгновенные, прогресс использует анимацию только при разрешённых системных анимациях.

Акцент обозначает основное действие, выбранную вкладку и фокус. Сообщения о состоянии содержат текст. Контрастный режим использует системные кисти Windows. Клавиатурный фокус виден на полях, кнопках, вкладках и чекбоксах. Подписи связаны с полями через UI Automation. У статуса есть объявление об изменении.

## Поведение

- Верхние вкладки — «Из DWG» и «По помещению». `Alt+D` и `Alt+P` переключают сценарии. `Ctrl+Enter` запускает активный сценарий, `Esc` закрывает настройки или окно. `Enter` активирует элемент в фокусе. Навигация внутри форм идёт сверху вниз. Для редактируемых полей сохранено стандартное контекстное меню.
- Ошибки заполнения показываются под полем и остаются видимыми до изменения значения. Фокус переходит к первому проблемному полю. Подсказка рядом с ограничениями объясняет, как переключить режим. Сообщения Revit и итог построения находятся над главной кнопкой.
- При отсутствии DWG вкладка показывает, что сделать на плане. При построении окно блокирует повторный запуск, показывает статус, а для DWG — процент. Отмена выбора элемента в Revit возвращает фокус на кнопку выбора.
- Настройки темы, масштаба и положения окна независимы от сохранения параметров построения. Положение восстанавливается в границах рабочей области. При недостатке высоты прокручиваются параметры. При недостатке ширины на большом масштабе доступна горизонтальная прокрутка параметров.
